# Summarize a SplitAlignerR result

Summarize a SplitAlignerR result

## Usage

``` r
# S3 method for class 'splitaligner_result'
summary(object, ...)
```

## Arguments

- object:

  A `splitaligner_result`.

- ...:

  Reserved.

## Value

A `summary.splitaligner_result` list with overall state counts, per-gene
state counts, finite numeric-evidence counts, active diagnostics, and
metadata.
