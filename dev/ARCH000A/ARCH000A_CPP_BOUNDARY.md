# ARCH000A recommended C++ boundary

## Move eventually

### Exact packed identities

C++ should own fixed-width retained-taxa bitsets, primitive-member bitsets, and
projected split bitsets. Hashes may accelerate tables, but equality and final
ordering must compare exact packed content.

### Truth construction

Restriction, suppression, fiber construction, primitive state templates,
composite member sets and projected queries should be one tested C++ kernel.
The kernel must have no fixed/free mode and no empirical gene topology input.

### Packed record

C++ should encode/decode a versioned typed record with explicit byte order,
dimensions and checksums. The R prototype fixed-width layout is a size and
round-trip experiment, not a frozen ABI. Production may remove redundant query
rows or use offsets after golden-vector equivalence is established.

### Byte LRU

C++ should account contiguous packed capacity exactly. The configured budget,
current bytes, high-water bytes, hits, misses, insertions and evictions should
be queryable. A decoded view may reference a cached record or bounded scratch;
its lifetime must end before the next gene if not cached.

### Empirical recovery

The existing validated numeric and Newick policies remain authoritative.
Empirical split indexing, deterministic query loops, direct raw/double row fill,
and internal counters are appropriate for C++ after cross-language golden tests.

## Keep in R

R should own:

- user input normalization and provenance;
- execution-plan reporting;
- temporary-path policy and user-visible diagnostics;
- conventional phylo support-label attachment;
- result classes and lazy/chunked derived views;
- paired fixed/free finalization roles;
- evidence summaries.

## Packed-size estimate

The prototype body formula for 302 taxa and 601 primitives is 23,027 bytes per
pattern. The exact authority compares this with the measured verbose R-plan size
distribution. A more compact C++ record may store only unique query groups plus
primitive-to-group IDs, but must prove exact equality for every authority
pattern before replacing the fixed prototype.

## No speed promise

ARCH000A measures R prototype construction, packing, disk and decode costs. It
does not convert those observations into an unmeasured C++ speedup claim.

## Required production sequence

1. Freeze typed schemas and byte-order/checksum rules.
2. Add cross-language bitset, split, fiber and record golden vectors.
3. Implement one-pattern truth construction and packed round trip in C++.
4. Implement exact byte-accounted packed LRU.
5. Implement atomic store completion and interruption tests.
6. Connect one-gene empirical recovery to bounded decoded views.
7. Add adaptive planning and local-scratch policy in R.
8. Re-run all current authorities and multi-platform RECERT.

No step is authorized for production by ARCH000A alone.
